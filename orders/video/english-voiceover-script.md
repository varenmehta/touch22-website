# Touch22 Order Desk: English voiceover script

Same timing as the Hindi script (video is 6:28). Warm and conversational, like walking a client through it, not a word-for-word translation. Voiced with Microsoft Edge TTS, en-IN-NeerjaNeural (see make/voiceover.py).

| Time | Step | Voiceover (English) |
|---|---|---|
| 0:01 | Intro | Hi! This is Touch22 Order Desk. Every order, one place. |
| 0:08 | Today | Right now, orders live in WhatsApp chats, and follow-ups live in someone's memory. With Order Desk, every order gets a number, tracked all the way to delivery. |
| 0:21 | 1. Overview | So, this is what you see in the morning. Your whole day, at a glance. What needs doing, what's running, and what's running late. And each task is just one button. |
| 0:41 | 2. WhatsApp order | A retailer sends an order on WhatsApp, just the way they normally would. The bot reads it, picks out the product, carat, weight, size and design, and sends a quick summary back. They tap confirm, and that's it. The order is now T434. |
| 1:18 | 3. Hindi and Hinglish | And they can write in Hindi, English, or Hinglish. Doesn't matter. If something's missing, the bot asks for just that one thing, in their language. |
| 1:54 | 4. Number and factory | That T-number stays with the order from the first message to delivery. Now, which factory? Order Desk suggests one, based on who's on time, who's got room, and who can do CAD. One tap, and it's sent. |
| 2:26 | 5. Factory confirms | The factory gets a clean message, same format every time, order number right on top. They reply however they like, and the dashboard just updates. |
| 2:53 | 6. CAD approval | For a new design, there's a CAD first. The factory sends it, it goes straight to the retailer, and they approve it with a tap. Production starts. |
| 3:25 | 7. Follow-ups | You don't have to chase anyone. Follow-ups go out on day six, eight and ten, then every day. Urgent orders get one daily. And each factory gets a single message with all their order numbers. |
| 4:05 | 7. Delays | If a factory says it'll be late, the order moves to Running late, and the retailer gets the new date on WhatsApp. No awkward calls. |
| 4:37 | 8. Quality check | When the piece arrives at the office, it's checked. All good? It's dispatched, and the retailer hears about it. |
| 4:56 | 9. Repair or wrong order | Something not right? Just pick the reason. It goes back to the same factory, with a clear return note and a new date. |
| 5:44 | 10. Reports | Which factory is actually on time? Which designs get customised the most? Now you know, straight from your own orders. |
| 6:17 | Outro | Touch22 Order Desk. A number for every order, the right factory, follow-ups on autopilot, and reports you can trust. |
